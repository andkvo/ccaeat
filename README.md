# ccaeat

CCA Extemporaneous Apologetics Timer app for iOS and Android (Expo/React Native).

## Features

- **Count Down mode**: configurable countdown up to 10:00 with required audible spoken verbal signals each minute from 9:00 to 1:00, plus 0:30 and 0:05, with matching visual prompts.
- **Count Up mode**: 0:00 count-up with required silent visual hand-signal prompts at 1:00, 2:00, 3:00, 4:00, 4:30, and 4:55.
- Count Down and Count Up cues can **flash the screen** and show a **large visual signal** to get attention without interrupting.
- Start/Pause/Reset controls.
- Portrait and landscape layouts, with a split view in landscape for quick mode switching and an expanded timer.
- Count Up stop-time display to report to judges.

## Run

```bash
npm install
npm run android
# or
npm run ios
```

For local development UI preview:

```bash
npm run start
```
